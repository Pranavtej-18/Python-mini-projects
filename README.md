# 🐍 Python Mini Projects

A collection of Python mini projects built while learning core programming concepts and problem-solving. This repository showcases practical implementations of Python fundamentals, object-oriented programming, file handling, user interaction, and logic building through real-world applications.

---

## 📌 Projects Included

### 📒 Contact Book
A command-line contact management application that allows users to:

- ➕ Add new contacts
- 🔍 Search contacts
- ✏️ Update existing contacts
- ❌ Delete contacts
- 📋 View all saved contacts

**Concepts Used**
- Python Functions
- Dictionaries
- Loops & Conditionals
- File Handling
- Exception Handling

---

### 🔐 Password Generator
A customizable password generator capable of creating strong and secure passwords based on user preferences.

**Features**
- Generate random passwords
- Custom password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters

**Concepts Used**
- Random Module
- String Module
- User Input
- Functions
- Conditional Logic

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/Python-mini-projects.git
```

### Navigate to the project

```bash
cd Python-mini-projects
```

### Run any project

Example:

```bash
python ContactBook/contacts_book_v2.py
```

or

```bash
python PasswordGenerator/final.py
```
